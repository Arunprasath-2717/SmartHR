# Dayflow Data Definitions

This directory will contain initial XML/CSV data records for the `dayflow_hrms` module:

## Planned Contents:

1. **Automated Actions & Cron Jobs**:
   - Scheduled actions (`ir.cron`) for anomaly polling and periodic data synchronization.

2. **Sequences & Numbering**:
   - Document sequences and unique code generators (`ir.sequence`).

3. **Default Master Data**:
   - Initial leave types, shift templates, and default department configurations.
