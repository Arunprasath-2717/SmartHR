# Architecture Decision Records (ADRs)

This directory hosts Architecture Decision Records (ADRs) capturing significant architectural choices, context, and consequences.

## Format

ADRs follow the standard format:
- **Title**: Short description of the decision.
- **Status**: Proposed, Accepted, Deprecated, or Superseded.
- **Context**: Background and rationale for the decision.
- **Decision**: What was chosen and why.
- **Consequences**: Positive and negative trade-offs.
